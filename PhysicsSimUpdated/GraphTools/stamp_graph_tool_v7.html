Plateau Summary — Metric
Bars show plateau mean ± SD per geometry (points at/after the plateau cutoff set below, using the same detector as Plateau Trimming). Letters mark Holm-adjusted pairwise Welch t-test groups — geometries sharing a letter are not significantly different (α = 0.05). Because the "replicates" here are timepoints within one run per geometry rather than independent repeats, treat these as a quick manuscript-figure summary, not a substitute for a proper replicated-trial ANOVA.
