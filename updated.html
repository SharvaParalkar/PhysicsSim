Measurement & capture
Timed capture

On Run, log metrics for a fixed simulated-time window (settle auto-pause off), with staggered drops 5→50 every 0.5 sim-s, then pause and save the CSV. Timing is sim-time so every shape covers the same physics interval even if one runs slower.

Applies equal-volume sizing + the standardized protocol, then runs each shape for the same span of simulated time.

Shape sensitivity

The p2p columns treat particles as spheres around their centroid, so they cannot distinguish a star from a cube. The mesh interlock metric tests real surface geometry instead — use mesh_interlock_depth_* (not the vertex-count index) for grip strength. Costly; enabled automatically by timed capture.
